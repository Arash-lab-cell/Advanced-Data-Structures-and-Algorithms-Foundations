# Advanced DSA Foundation

Java implementation of Advanced DSA Foundations coursework — arrays (1D/2D) and array techniques, bit manipulation, recursion, modular arithmetic & GCD, hashing, and sorting (counting sort, merge sort, quicksort, comparator-based problems). Solved and documented as part of interview preparation.

## Progress

**26 problems** solved across **5 of 8** topics. Each problem has its own `README.md` (problem statement, approach, dry run, complexity analysis, key learnings) and a `Solution.java` file.
